# Sample candidate (fictional)

Everything in this folder is invented to show what a filled-in workspace looks
like after onboarding and a first Scout run: the person, the university, the
organisations, the postings and the links (all on example.com). None of it is
real, so don't apply to anything here.

Try it:

```
python tools/pipeline.py --workspace examples/sample-candidate today
python tools/pipeline.py --workspace examples/sample-candidate dashboard
python tools/pipeline.py --workspace examples/sample-candidate calendar
python tools/pipeline.py cv examples/sample-candidate/cv.json
```

Then open `examples/sample-candidate/dashboard.html` and `cv.html` in a browser.
