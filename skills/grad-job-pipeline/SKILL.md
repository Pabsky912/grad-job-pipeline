# grad-job-pipeline

This skill is a pointer to the grad-job-pipeline kit
(https://github.com/Pabsky912/grad-job-pipeline).

1. Find the kit's folder (the one containing `AGENTS.md` and `docs/`). If it is
   not on this computer, ask the person where they cloned it, or offer to clone
   it with `git clone https://github.com/Pabsky912/grad-job-pipeline`.
2. Read `AGENTS.md` in that folder and follow it. It routes every request to the
   right method file in `docs/` and explains the workspace (`my-search/`).
3. If `my-search/profile.md` is missing or has `TODO`s, start with onboarding
   (`docs/01_ONBOARDING.md`).

Ground rules from `AGENTS.md` always apply: never invent postings, dates or
facts; open every posting before judging; draft but never send; no LinkedIn
automation; keep personal data in `my-search/`.
